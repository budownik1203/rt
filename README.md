# Latarnia: folder projektu

To pakiet przekazania projektu gry **Latarnia** dla nowej instancji Claude (lub innego współpracownika).

**Jak zacząć z nowym Claude:** daj mu dostęp do tego folderu i napisz: „Przeczytaj CLAUDE.md i dokumenty z folderu docs, potem zapytaj mnie, od czego zaczynamy.”

- `CLAUDE.md`: prompt startowy (kim jesteś, jak pracujemy, stan projektu).
- `docs/`:
  - pełny koncept;
  - historia decyzji;
  - lista zadań;
  - plan budowy gry w Godot 4 + C#;
  - opis potoku grafiki.
- `assets/`: archiwa do rozpakowania:
  - modele dla Godota (.glb);
  - skrypty grafiki;
  - grafiki pokazowe;
  - makiety interfejsu.
